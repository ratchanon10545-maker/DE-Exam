คู่มือใช้งาน
============

โครงสร้างไฟล์:
index.html
style.css
script.js
questions/text.txt

เว็บไซต์อ่านข้อสอบจาก questions/text.txt อัตโนมัติ ไม่มีปุ่มอัปโหลด
หลังเลือกคำตอบ ระบบจะแสดงถูก/ผิด เฉลย และคำอธิบายทันที และล็อกตัวเลือกข้อนั้น

ข้อสำคัญ: เบราว์เซอร์มักไม่อนุญาตให้ fetch ไฟล์เมื่อเปิด index.html แบบ file://
ให้เปิด Command Prompt ในโฟลเดอร์นี้ แล้วรัน:
python -m http.server 8000
จากนั้นเข้า http://localhost:8000

หากต้องการเปลี่ยนตำแหน่งไฟล์ ให้แก้บรรทัด const FILE ใน script.js
ไฟล์ต้องอยู่ในพื้นที่ที่เว็บเซิร์ฟเวอร์ให้บริการ ไม่สามารถระบุ path เครื่องผู้ใช้เช่น C:\... แล้วอ่านโดยตรงจากเว็บได้

รูปแบบข้อสอบ:
Q: คำถาม
A: ตัวเลือก A
B: ตัวเลือก B
C: ตัวเลือก C
ANSWER: B
EXPLANATION: คำอธิบาย (ไม่บังคับ)

เว้นบรรทัดว่างระหว่างข้อสอบแต่ละข้อ รองรับตัวเลือก A-J
